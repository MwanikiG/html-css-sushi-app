# SushiMan Website

A simple sushi restaurant website built using HTML, CSS, and JavaScript.

## Features
- Homepage with navigation
- Menu section
- Shopping cart functionality (incomplete)
- Responsive design

## Future Plans
- Improve JavaScript functionality
- Migrate to Next.js for better performance and maintainability

## Setup
Clone the repository and open `index.html` in a browser.

```sh
# Clone the repository
git clone https://github.com/your-username/sushiman.git
cd sushiman
```
